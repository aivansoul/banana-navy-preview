# Politique de confidentialité

Cette page décrit comment Banana Navy SRL collecte, utilise et protège les données personnelles que vous nous confiez via ce site.

## Responsable du traitement

Banana Navy SRL — Rue Antoine de Saint-Exupéry 2, 6041 Charleroi, Belgique. Contact RGPD : hello@banana-navy.com.

## Données collectées

Formulaire de contact : nom, email, entreprise, message. Aucune donnée n'est collectée passivement (pas de tracking publicitaire).

## Finalités

Vous recontacter, qualifier votre demande, planifier l'audit gratuit. Aucune utilisation marketing sans consentement séparé.

## Conservation

Données conservées 24 mois après le dernier échange, sauf demande de suppression anticipée.

## Vos droits

Vous disposez d'un droit d'accès, de rectification, d'effacement, d'opposition et de portabilité. Pour les exercer, écrivez-nous à hello@banana-navy.com. Vous pouvez également déposer une réclamation auprès de l'Autorité de Protection des Données (Belgique).
